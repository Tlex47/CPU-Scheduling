# CPU Scheduling Simulator (Term Project)

โปรแกรมจำลองและเปรียบเทียบประสิทธิภาพการจัดสรรหน่วยประมวลผล (CPU Scheduling) ในรูปแบบ Web Application

---

## คุณสมบัติของโปรแกรม

1. **การกำหนดโปรเซสและ Burst Time (BT):**
   - รองรับการป้อนจำนวนโปรเซส ($P_1, P_2, \dots, P_n$)
   - สามารถป้อนค่า Burst Time ด้วยตนเอง หรือใช้ปุ่มสุ่มค่า Burst Time อัตโนมัติ
2. **อัลกอริทึมที่รองรับ:**
   - **FCFS**
   - **SJF**
   - **Round Robin**
3. **การแสดงผลลัพธ์:**
   - แสดงตารางข้อมูล: Process, AT, BT, ST, CT, TAT และ WT
   - คำนวณและแสดงค่า **AVG WT** ของแต่ละอัลกอริทึมเพื่อนำมาเปรียบเทียบกัน

## ชุดทดสอบอัลกอริทึม

### 1. FCFS
- **ข้อมูลที่ใส่:** จำนวนโปรเซส 3, BT: P1 = 5, P2 = 2, P3 = 4
- **ผลที่ควรได้:** ลำดับ P1 → P2 → P3, WT: P1 = 0, P2 = 5, P3 = 7, AVG WT = 4.00

### 2. SJF
- **ข้อมูลที่ใส่:** จำนวนโปรเซส 3, BT: P1 = 6, P2 = 2, P3 = 4
- **ผลที่ควรได้:** ลำดับ P2 → P3 → P1, WT: P1 = 6, P2 = 0, P3 = 2, AVG WT = 2.67

### 3. Round Robin (RR)
- **ข้อมูลที่ใส่:** จำนวนโปรเซส 3, BT: P1 = 5, P2 = 3, P3 = 1, Time Quantum = 2
- **ผลที่ควรได้:** ลำดับที่เสร็จ P3 → P2 → P1, WT: P1 = 4, P2 = 5, P3 = 4, AVG WT = 4.33
